# ResumeCraft 发布记录

## v1.0.10

发布日期：2026-09-14

### 变更：双栏收尾（一行两个模块）+ 精密行距

v1.0.9 把版式从逐行堆叠里拉回来，但“一条栏目一行”仍然让短栏目（求职目标、成果、链接等）独占一整行、右半页空着，且行距偏松。本次继续在共享版式层改造，26 个模板同时受益：

- **双栏收尾**：相邻的短栏目并排成一行两个模块（`paginate` 产出 `pair` 单元，导出渲染 `.pair` 网格、SPA 画布 `renderPageUnits` 同步）。配对遵循三条约束：
  - **只并排相邻栏目**，因此不会打乱栏目顺序（此前按固定 id 挑配对，把 education/skills/awards/links 整体提到了 target/profile/experience 之前）；
  - **必须真正省下纵向空间**才配对（并排高度 < 顺排高度 − 20px），否则半宽折行会让正文变高、反而更费版面；
  - **并排上限随半栏宽度等比收紧**（页预算 × 0.4 × 半栏字数/33）。侧栏布局主栏只有 128mm，半栏 58mm 时上限约 275px，因此只有求职目标/个人简介、教育经历/链接这类短栏目并排，项目与实践保持整宽通排（否则条目标题会被挤成两行）。
  - `pair` 是原子单元，放不下当前页剩余空间时**退化成两个整宽栏目**继续排，避免为等一整对而空出大半页、形成只有一两行的尾页。
  - 时间轴布局不配对：左时间栏是它的识别特征，没有时间栏就不是时间轴。
- **精密行距**（导出与 SPA 同步）：正文 9pt 行高 1.6→1.5、条目下边距 4mm→2.6mm、栏目上边距 5.5mm→3.8mm、栏目标题下边距 2.2mm→1.6mm、元信息行高 1.4→1.35、主栏内边距 13mm→12mm、时间轴时间栏 18mm→15mm，侧栏一套同步收紧。
- **SPA 画布对齐导出**：预览此前已自行漂移（正文 8pt vs 导出 9pt、元信息 7pt vs 7.8pt、多处内边距差数毫米）。分页估算按导出 CSS 标定，预览更松会让两端断点错位；现已逐项对齐，并新增参数化测试逐项比对两张样式表里真正影响分页的数值。

### 修复

- **导出正文被裁在 A4 底边之外**（P1，8/78 份样本）：`plain` 布局在一串布局条件里没有分支，落到 `sidebar` 的页面预算上，凭空多出近百像素可用高度；现改为按布局直接查表。
- **计价口径用错列**（P1）：栏目标题与条目成本按“栏目 id 是否属于侧栏”取用侧栏口径，于是 plain/banner/grid/line 主栏里的技能/成果被按 44mm 侧栏的每行字数（15 字）计价。现改为按实际排布的那一列取用（`paginate(in_sidebar=...)`），正文切片上限同理。
- **侧栏首页页头未计价**（P1）：侧栏首页还要放姓名 + 联系方式 + 简介，此前没有从第一页预算里扣掉，联系方式多或简介长的简历会把侧栏内容裁掉。现按同一套度量推算页头高度（姓名行 + 每字段一行 + 简介行数）并从首页扣除。
- **侧栏重复渲染基本信息**（P2）：侧栏布局的姓名、联系方式、简介已经由侧栏页头呈现，`basics` 又作为栏目渲染一遍，同一段内容在侧栏出现两次并白占一行栏目标题。侧栏栏目现只为技能与成果。
- **正文换行被吃掉**（P2）：`render_markdown` 为归并 `- ` 列表先按换行分段，之后又用空串拼接，把作者分好的行黏成了一行（截图里 “9/153具身智能系统概论…”），而 SPA 预览的 `mdLite` 用 `<br/>` 拼接——两端显示不一致。现统一用 `<br>` 拼接。
- **行尾换行多算一整行**（P2）：`content_line_count` 把行尾 `\n` 当成一整行，而它渲染出来只是行尾 `<br>`（不产生行盒）。真实数据里正文大多以换行结尾，于是每条内容都凭空高一整行、页面被过早切断。
- **续段重复条目标题**（P2）：长正文切片后每一段都重新渲染 `<h3>` 标题，同一个条目看起来出现了两次。续段现只带正文。
- **plain/timeline 页头行被拉伸**（P2）：页面是“页头 + 正文”两行网格，只声明 auto 行时 `align-content: stretch` 会把富余高度分一半给页头，短内容页在联系方式下方出现约 80-110px 的空白带。banner/grid/line 早已钉住行高，plain/timeline 补上 `grid-template-rows:auto 1fr`。

### 变更：估算改为实测标定

- 新增 `scripts/calibrate_layout.py`（用真实渲染器产出校准探针）+ `web/scripts/measure_calib.mjs`（在浏览器里读真实几何：用 Range 数行盒、读计算行高、量页头的自然高度，而不是从 CSS 算术反推）+ `web/scripts/dump_page.mjs`（导出单页 DOM 结构与高度，用于定位估算-渲染偏差）。`LAYOUT_METRICS`/`PAGE_BUDGET_PX` 全部按实测重标，并按安全一侧取整（行高与固定成本向上、每行字符数向下）——低估会让导出正文越过 A4 底边被裁掉，高估只是浪费版面。
- 实测推翻了“衬线字面更宽、每行少容纳一成字符”的假设：Georgia/Times 对中文会落到 SimSun，中文字宽不变，衬线模板与同布局的非衬线模板每行字数一致，因此不再需要单独的衬线缩放。
- 估算不再为“标题与栏目标题同名的条目”收取标题行成本（这类条目不渲染 `<h3>`，求职目标/个人简介 这类单条目栏目正属于此），扣除量即实测标题行高度，因此只可能更紧、不会低估。
- `summarize_metrics.py` 增加验收门槛：任何一页不得裁切，非末页填充不得低于 80%。

### 验证

- 26 个模板 × 3 种密度样本（真实简历 / 长正文 / 字段密集）共 78 份导出：**84 页、72 份单页、零裁切、非末页零半满**（改造前为 8 份裁切、第二页普遍只有 13-28% 填充；`real-*` 样本此前多数需要 2 页，现全部 1 页）。密集样本 `long-*` 也从 2 页收敛到 1 页（时间轴除外）。
- 后端 pytest 143 项、前端 vitest 7 项、`tsc -b --noEmit` 全部通过；新增的回归测试覆盖正文换行、列表/加粗/斜体、行尾换行、续段标题只渲染一次，以及预览与导出排版常数逐项一致。

### 已知限制

- 时间轴布局（晨光/赭金）保持单列不配对，密集内容下仍可能产生偏薄的尾页；`fields` 样本首页 84%、次页 15%。它的估算偏保守约 4%，属安全一侧。
- 侧栏布局在内容较短时（例如 `real-*` 样本）页面底部留白较多（约 54% 填充）：同一份内容分到两列后每列都更矮，这是两栏版式的固有特性，不是分页错误——单栏布局同样的内容能填到 88%。若希望追平，可让侧栏按内容长度动态承接更多栏目，但栏目归属会随内容变化，本次未采用。

## v1.0.9

发布日期：2026-09-13

### 变更：版式去竖排化（密度重设计）

针对“单栏版式逐行堆叠、留白多、容易分页”的结构性问题，在共享版式层动刀（26 个模板同时受益），而非逐模板修补：

- **时间上标题行**：所有非时间轴布局把 `period` 从元信息行移出、右对齐到条目标题行行尾（线式布局既有做法推广为全局规范），每个带时间的条目省一行；实现上合并了 `block_html` 与 `line_block_html`（统一为 `entry-row`/`entry-period`），时间轴保持左栏时间列。
- **plain/timeline 补紧凑页头**：居中姓名 + 联系方式行 + 分隔线（复用线式页头结构、更轻的分隔线），取代原来整节“基本信息”——单栏正文不再为联系方式付一个栏目头 + 空白条目的代价，外观也更接近真实简历。五种单栏布局的正文统一从求职目标开始（`layoutMainIds` 随之简化）。
- **收紧垂直节奏**（导出与 SPA 同步）：栏目上边距 7mm→5.5mm、条目下边距 5mm→4mm、栏目标题下边距 3mm→2.2mm、主栏上边距 14mm→13mm、侧栏栏目上边距 9mm→6.5mm、侧栏条目边距 4mm→3mm。
- **编辑模式高度对齐导出**：“添加来源”按钮改为绝对定位（原先透明但占位，每个栏目多 ~20px）、编辑模式栏目标题分隔线改用 box-shadow——编辑画布的分页不再比导出虚高。
- **分页模型随版式更新**：`LAYOUT_METRICS`/预算按新 CSS 重新推导，校准工具复跑 78 份样本（26 模板 × 3 密度），零溢出；真实简历在 plain 布局下由 2 页（且曾溢出）变为 **1 页（92% 填充）**。

### 验证

- 后端 pytest 131 项、前端 vitest 6 项、`tsc -b && vite build` 全部通过；兼容性测试的 `HEADER_LAYOUTS` 扩为五种页头布局，SPA 同步断言增加 plain/timeline 页头样式检查。
- 浏览器实测：真实简历在 minimal 下 1 页（页头 + 紧凑正文）、时间轴下 2 页零溢出，时间上标题行、页头、续页标记渲染正确。

### 修复

- **侧栏布局内容重复**（P1）：v1.0.7 重构布局分支时，侧栏布局（10 个模板）的主栏栏目列表被误改为 7 栏（含技能、成果），而这些栏目同时仍渲染在侧栏——同一份简历的“技能”“成果”在第 1 页出现两次。主栏恢复为五栏目（求职目标/个人简介/项目与实践/教育经历/链接与作品集），导出渲染器与 SPA 画布同步修复。
- **导出内容溢出 A4 底边**（P1）：分页权重只按“字段个数×固定值”计价，长字段值（到岗安排、核心要求等）折行后的高度、栏目标题行与条目边距被系统性低估。实测样例中 plain 溢出 107px、时间轴 132px、横幅 80px，末尾栏目被静默裁剪。
- **提前分页**（P2）：新骨架（grid/line/timeline）预算沿用手感值，密集内容下首页只填 68-84% 就断页，第 2 页只剩十几行。

### 变更：分页权重模型像素化

- 权重从抽象单位改为**估算渲染高度（px）**：正文按“每行字符数 → 行数 × 行高”、元信息按主栏 flex-wrap（约 65 字符/行）与侧栏逐字段一行（约 15 字符/行）分别折行、栏目标题按“每页每栏目一次”计价（页内首栏目 margin 归零成本更低）、line/timeline 保留各自的每条目装饰成本。预算即页面可用高度（A4=1122px 减页头与页边距）。
- 每个布局的常数由导出 CSS 反推，并用无头 Chromium 实测校准：26 个模板 × 3 种密度样本（真实简历 / 长正文 / 字段密集）共 78 份导出 HTML 逐页测量内容高度与溢出，迭代 5 轮后**全部零溢出、首页填充 77-92%**。
- 校准工具入库：`scripts/gen_samples.py`（生成多密度样本导出）、`web/scripts/measure_pages.mjs`（无头浏览器逐页测量）、`scripts/summarize_metrics.py`（汇总）。后续新增模板/调整版式可直接复跑。
- SPA 预览（`lib/resume.ts`）与导出渲染器逐项镜像同一模型，预览分页与导出断点保持一致；`streamItems` 新增 layout 参数。

### 验证

- 浏览器实测：真实简历（机器人数据采集员 v4）在 minimal 下 2 页、时间轴下 2 页，逐页零溢出、无重复栏目，页数与导出测量一致；切换模板后工作副本已还原。

## v1.0.7

发布日期：2026-09-13

### 新增

- 模板库扩充至 26 个内置模板，新增**三种全新版式骨架**与六个基于 2026 网络优质简历样式调研的模板（注册表 `app/templates.py`；三种版式此前均无同质模板）：
  - **表格表单版式**（`grid`，新骨架）：模仿传统 Word 表格简历——居中表头（姓名 + 联系方式单元格行）+ 每个栏目一个带边框的表格框，栏目标题为实底表头行，行列规整，适合国企、银行、校招与公职类岗位。新增 `atlas`（雅蓝表格模板）、`flint`（灰石表格模板）。
  - **经典线式版式**（`line`，新骨架）：哈佛式经典学术简历——居中大姓名 + 居中联系方式行 + 页头下方粗横线，栏目标题居中加字距，条目时间从元信息行取出、右对齐到标题行行尾，条目之间以发丝线分隔。新增 `quill`（羽墨线式模板，全衬线黑白，适合高校/科研/留学）、`indigo`（靛青线式模板，适合技术/数据/研究类岗位）。
  - **时间轴版式**（`timeline`，新骨架）：条目左侧独立时间栏 + 中线贯穿 + 强调色圆点标注时间节点，经历脉络一目了然，适合互联网、产品、运营与市场类岗位。新增 `lumen`（晨光时间轴模板）、`meridian`（赭金时间轴模板）。
- 本轮调研结论：中文招聘市场里"表格式简历"（熊猫办公表格式模板 791 套、智联"通用表格"分类）在国企/校招场景仍是主流审美；哈佛职业服务中心推广的"居中姓名 + 全大写栏目标题 + 横线"单栏式是学术与投递场景的经典范式；时间轴布局在中文简历产品中广泛用于强调经历脉络。三种新骨架均延续"中性色主导 + 单一强调色"原则，且保持白底深字、无图片图标，机器解析友好。
- 新骨架的实现范围：导出渲染器（`app/services.py`）与 SPA 画布（`Canvas.tsx` + `styles.css`，CSS 变量驱动）同步支持三种新骨架，包括各自的分页预算（grid 2100 / line 2300 / timeline 2200）、跨页"（续）"标题、续页页头；线式/时间轴布局把 `period` 字段从元信息行移出（线式右对齐到标题行，时间轴放入左侧时间栏），其余布局不受影响。

## v1.0.6

发布日期：2026-09-13

### 变更：模板系统解耦与前端模块化

- **模板单一事实源**：模板注册表从 `app/services.py` 迁至 `app/templates.py`，每份描述符（布局 + 11 个色板 + 衬线开关）只定义一次；`/api/templates` 与简历负载（`template_info_response`）下发完整 `tokens`/`serif`/`layout`。
- **画布主题变量化**：SPA 画布不再维护逐模板样式——删除 `styles.css` 中 20 套硬编码 `theme-*` 画布主题与 20 条 `thumb-*` 缩略图规则（约 170 行），画布/横幅/侧栏改为消费 API 下发的 CSS 自定义属性（`--t-*`，经典色板作为回退值）；模板弹窗缩略图由色板实时生成。新增模板自此只需改 `app/templates.py` 注册表，前端零改动。
- **前端模块化拆分**：548 行单体 `App.tsx` 拆分为 `lib/`（resume 领域逻辑与 mdLite）、`lib/templates.ts`（模板描述符 → CSS 变量）、`components/`（Canvas、Picker、TemplateModal、StageToolbar、BenchHead、通用 UI）、`pages/`（Home/Facts/Profiles/Resumes/Composer/Editor/TemplateLibrary 七个页面）与瘦壳 `App.tsx`；分页/分片逻辑原样迁移，前端预览与导出断点仍逐字对齐。
- **模板库创建链路补全**：模板库“用此模板创建简历”此前只跳转岗位画像、所选模板被丢弃（新临时简历一律回退最早模板）；现在所选模板会带入临时简历创建（`POST /api/linked-resumes?template_version_id=…`），临时简历/正式简历继续沿用。
- **首页收敛为三个主入口并列**：移除首页“模板库”大图标卡片（落实交互设计 3.1/4.4 与 ui-audit GAP-11 的产品决策），模板入口保留在简历工作台页与编辑器/临时简历的模板选择弹层；三个入口并列一行，“简历工作台”居首并改为深色渐变主卡片（白字、浅色图标、悬浮上浮），提升视觉层级。

## v1.0.0

发布日期：2026-09-11

### 版本定位

v1.0.0 是ResumeCraft 的首个正式本地版本，交付一条可重复使用的简历生产链路：

```text
事实资料与证据
    -> 岗位需求画像
    -> 联动临时简历
    -> 转化并创建正式简历 v1
    -> 正式简历工作副本
    -> 人工编辑
    -> 不可变正式版本
    -> 独立 A4 HTML 交付
```

### 本版本范围

- 默认本地用户与工作区；
- 结构化事实资料、分类字段、扩展字段和审计记录；
- 证据文件与链接管理；
- 岗位需求画像；
- 临时简历事实选择与实时预览；
- 临时简历转为正式简历，并立即创建“格式化简历、未润色”的正式 `v1`；
- 正式简历工作副本自动保存与显式正式保存；
- 线性不可变版本、历史查看和恢复到工作副本；
- 事实来源变化待处理提醒；
- 独立严格 A4 HTML 导出。

### 正式编辑交互

正式简历工作区不再把编辑控件直接嵌入 A4 纸面，而是采用：

- 中央 A4 页面只读预览，结构与导出模板保持一致；
- 点击区块打开居中编辑卡片，集中修改标题、可见结构字段和正文；
- 右键区块打开靠近点击位置的快捷菜单，提供“编辑文本”和“添加来源”等操作；
- 编辑结果写回结构化工作副本，A4 预览同步更新；
- 浏览器默认右键菜单不再与编辑面板竞争。

### 本版本不包含

- AI 辅助编辑；
- 证据附件 ZIP 与 `manifest.json` 交付包；
- 多用户、登录、权限和跨工作区隔离；
- PostgreSQL、对象存储和异步任务实现；
- 模板可视化管理与模板切换。

### 技术基线

- 前端：TypeScript + React SPA，位于 `web/`；
- 后端：FastAPI + SQLAlchemy，位于 `app/`；
- 数据库：SQLite，文件为 `data/resume_workbench.db`；
- 导出渲染：`app/services.py` 内置的结构化内容渲染器，直接输出独立 A4 HTML。

### 验证

- 前端生产构建通过；
- 后端测试通过：27 项。
