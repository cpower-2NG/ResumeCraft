# ResumeCraft 发布记录

## v1.0.3

发布日期：2026-09-13

### 新增

- 模板库扩充至 10 个内置模板，新增四个基于 2025-2026 网络优质简历样式调研的版式（注册表 `app/services.py`）：
  - **松屿绿侧栏模板**（`pine`，侧栏双栏）：深松绿侧栏配苔绿点缀，适合产品、运营与可持续行业岗位；
  - **勃艮第侧栏模板**（`merlot`，侧栏双栏）：酒红侧栏配玫瑰金细节，适合金融、法务、品牌与高管岗位；
  - **玄墨极简模板**（`ink`，单栏通排）：黑白灰极简排版，机器解析兼容性最好，适合外企与跨岗位通用投递；
  - **鎏金横幅模板**（`brass`，横幅单栏）：暖褐横幅呈现姓名与联系方式，铜金细节，适合市场、教育与商务岗位。
- 新模板遵循"中性色主导 + 单一强调色"的通用设计原则：强调色只用于姓名、栏目标题、粗体与链接，正文保持深灰，保证屏显与打印对比度。

### 修复

- 预览画布基础侧栏底色与 `classic` 模板导出色板存在的历史色差（`#15363d` → `#163b43`），预览与导出颜色一致。

### 测试

- 新增 `tests/test_template_compatibility.py`（32 项）：内置模板描述符契约、全部模板 A4 导出渲染与分页（含跨页"续"标记）、用户内容转义、SPA 预览 CSS 与注册表同步检查、启动建库到 `/api/templates` 选择、转正式、保存与导出的 API 全链路验证。

### 验证

- 后端 65 项、前端 vitest 4 项、`pnpm build` 全部通过；真实数据库启动后自动补建 4 个新模板行，`/api/templates` 返回 10 个模板且 layout 正确；浏览器实测模板库页面 4 个新模板预览渲染正常。

## v1.0.2

发布日期：2026-09-12

### 新增

- 模板可选择、可替换：内置“经典侧栏 / 深蓝聚焦 / 简约无侧栏”三个代码渲染模板，工作副本内切换、正式保存后形成“模板调整”新版本；历史版本固定原模板。模板注册表（`app/services.py`）随新模板自动扩展选择界面。
- 受控 Markdown 渲染：正文支持**粗体**、*斜体*、无序列表和链接（画布预览与导出 HTML 一致）；编辑卡片提供格式工具条（粗体/斜体/列表/链接）。
- 待处理事项点击后跳转至对应简历并滚动定位、闪烁高亮受影响条目。
- 预览工具条：放大/缩小/适应窗口和首末页跳转；工作台上下文栏随滚动压缩为单行。
- 岗位画像支持“新简历身份”分叉：复制当前正式版本到新身份工作副本，首次保存从 v1 开始（原因 `identity_copy`）。
- 资料不足时创建临时简历显示提醒模态（去资料库补充 / 继续制作）；已归档或删除的已选资料在临时简历中给出明确提示。
- 资料库首页新增最近修改预览和非阻塞质量提示（缺证据/缺标签）；事实编辑卡片展示修改记录（审计）。
- 正式简历列表在存在未完成副本时优先提供“继续上次工作”入口。

### 调整

- 取消独立的来源/证据侧栏方案：来源信息以提醒区形式内嵌在条目编辑卡片（含原始事实摘要、同步状态、证据数量提示与用户/AI 内容标记），交互设计书第 9 章已同步修订。
- 修复“求职目标”栏目标题与条目标题重复：目标条目标题改用岗位方向，渲染层对与栏目同名的条目标题不再重复显示；提供目标块重建的修复脚本。

## v1.0.0

发布日期：2026-09-11

### 版本定位

v1.0.0 是ResumeCraft 的首个正式本地版本，交付一条可重复使用的简历生产链路：

```text
事实资料与证据
    -> 岗位需求画像
    -> 联动临时简历
    -> 转化并创建正式简历 v1
    -> 正式简历工作副本
    -> 人工编辑
    -> 不可变正式版本
    -> 独立 A4 HTML 交付
```

### 本版本范围

- 默认本地用户与工作区；
- 结构化事实资料、分类字段、扩展字段和审计记录；
- 证据文件与链接管理；
- 岗位需求画像；
- 临时简历事实选择与实时预览；
- 临时简历转为正式简历，并立即创建“格式化简历、未润色”的正式 `v1`；
- 正式简历工作副本自动保存与显式正式保存；
- 线性不可变版本、历史查看和恢复到工作副本；
- 事实来源变化待处理提醒；
- 独立严格 A4 HTML 导出。

### 正式编辑交互

正式简历工作区不再把编辑控件直接嵌入 A4 纸面，而是采用：

- 中央 A4 页面只读预览，结构与导出模板保持一致；
- 点击区块打开居中编辑卡片，集中修改标题、可见结构字段和正文；
- 右键区块打开靠近点击位置的快捷菜单，提供“编辑文本”和“添加来源”等操作；
- 编辑结果写回结构化工作副本，A4 预览同步更新；
- 浏览器默认右键菜单不再与编辑面板竞争。

### 本版本不包含

- AI 辅助编辑；
- 证据附件 ZIP 与 `manifest.json` 交付包；
- 多用户、登录、权限和跨工作区隔离；
- PostgreSQL、对象存储和异步任务实现；
- 模板可视化管理与模板切换。

### 技术基线

- 前端：TypeScript + React SPA，位于 `web/`；
- 后端：FastAPI + SQLAlchemy，位于 `app/`；
- 数据库：SQLite，文件为 `data/resume_workbench.db`；
- 导出渲染：`app/services.py` 内置的结构化内容渲染器，直接输出独立 A4 HTML。

### 验证

- 前端生产构建通过；
- 后端测试通过：27 项。
