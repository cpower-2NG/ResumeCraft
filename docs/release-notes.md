# ResumeCraft 发布记录

## v1.0.1

发布日期：2026-09-12

### 修复

- 正式简历与导出 HTML 的栏目标题不再逐条目重复：分页按栏目聚合标题，跨页续排时标题追加“（续）”；预览与导出使用同一套分页权重，分页位置保持一致。
- 仅打开简历不再把工作副本标记为“有未保存修改”：前端以载入内容为基线，只有真实修改才自动保存草稿。
- 从历史版本回退后的正式保存现在记录 `rollback` 版本原因；恢复当前版本（放弃修改）会将工作副本重置为干净状态。
- 正式简历工作区新增“放弃修改”按钮和离开确认（保存正式版本 / 保留工作副本并离开 / 放弃未保存修改）。
- 支持在右键菜单和编辑卡片中移除条目、上移/下移排序事实条目。
- 新增区块级版本对比接口与“对比当前”视图。
- 新增全局搜索（覆盖事实、证据、画像、招聘机会、正式简历）和右下角待处理事项入口（分组列表、点击跳转对应简历）。
- 首页新增“近期正式简历”；岗位画像列表显示更新时间、招聘机会数量和正式简历关联；画像编辑增加取消操作。
- 证据弹层支持“标记失效”；事实编辑弹层标题栏固定显示，支持 Esc/点击遮罩关闭。
- 修复事实编辑弹层打开时滚动位置错误；来源标记改为条目右上角徽标，不再与标题粘连；编辑模式“添加来源”按钮改为悬停显示。
- 提供旧格式工作副本修复脚本（`scripts/repair_working_copies.py`），依据来源事实重建缺失的结构化字段。
- 移除原型阶段的遗留代码与死模板（`app/models.py`、`app/database.py`、`app/seed.py`、`app/recommend.py`、`app/templates/`、`app/static/`），导出渲染为 `app/services.py` 内实现。

### 验证

- 后端测试 28 项通过；前端 vitest 4 项通过；前端生产构建通过。

## v1.0.0

发布日期：2026-09-11

### 版本定位

v1.0.0 是ResumeCraft 的首个正式本地版本，交付一条可重复使用的简历生产链路：

```text
事实资料与证据
    -> 岗位需求画像
    -> 联动临时简历
    -> 转化并创建正式简历 v1
    -> 正式简历工作副本
    -> 人工编辑
    -> 不可变正式版本
    -> 独立 A4 HTML 交付
```

### 本版本范围

- 默认本地用户与工作区；
- 结构化事实资料、分类字段、扩展字段和审计记录；
- 证据文件与链接管理；
- 岗位需求画像；
- 临时简历事实选择与实时预览；
- 临时简历转为正式简历，并立即创建“格式化简历、未润色”的正式 `v1`；
- 正式简历工作副本自动保存与显式正式保存；
- 线性不可变版本、历史查看和恢复到工作副本；
- 事实来源变化待处理提醒；
- 独立严格 A4 HTML 导出。

### 正式编辑交互

正式简历工作区不再把编辑控件直接嵌入 A4 纸面，而是采用：

- 中央 A4 页面只读预览，结构与导出模板保持一致；
- 点击区块打开居中编辑卡片，集中修改标题、可见结构字段和正文；
- 右键区块打开靠近点击位置的快捷菜单，提供“编辑文本”和“添加来源”等操作；
- 编辑结果写回结构化工作副本，A4 预览同步更新；
- 浏览器默认右键菜单不再与编辑面板竞争。

### 本版本不包含

- AI 辅助编辑；
- 证据附件 ZIP 与 `manifest.json` 交付包；
- 多用户、登录、权限和跨工作区隔离；
- PostgreSQL、对象存储和异步任务实现；
- 模板可视化管理与模板切换。

### 技术基线

- 前端：TypeScript + React SPA，位于 `web/`；
- 后端：FastAPI + SQLAlchemy，位于 `app/`；
- 数据库：SQLite，文件为 `data/resume_workbench.db`；
- 导出渲染：`app/services.py` 内置的结构化内容渲染器，直接输出独立 A4 HTML。

### 验证

- 前端生产构建通过；
- 后端测试通过：27 项。
